# Canal Character Package

This package will hold the reusable exported character sheets that interact with the Canal fields. Static field art must be completed before a final sheet is cut, because each animation needs an authored approach and depth layer.

| Sheet | Required first-use actions | Canal anchors |
| --- | --- | --- |
| `guest-base` | walk, stand, basic-sauna threshold, queue, shop stop, sit/idle | entrance, shop, workshop door, quay seats |
| `guest-water` | shower rinse, plunge entry, plunge sit, exit | shower, cold plunge, queue |
| `master-base` | walk, indoor threshold, outdoor Aufguss stance | workshop door, Gus Master yard |
| `master-tools` | towelwork, hand fan, rain ladle, infusion kit overlays | outdoor Gus yard / later programme asset |
| `service-host` | idle at port, short walk, towel collect | shop port / later towel anchors |
| `technician` | arrive, tool/repair loop, leave | eligible technical module fields |

All appearance palettes remain separable from behaviour. No sheet encodes guest goal, age, name, gender or ability as a mechanical type.
