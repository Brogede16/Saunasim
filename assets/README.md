# Asset Workspace

- `source/`: approved source/reference art only; never overwrite originals.
- `production/`: final, runtime-ready exported assets.
- `sprites/`: character bases, overlays and animation sheets.
- `effects/`: shared steam, water, splash, weather and construction effects.
- `ui/`: icons, ingredient marks, buttons and program-card visual elements.

Every production asset must be traceable to its asset-card ID and visual/animation contract in `docs/`.
