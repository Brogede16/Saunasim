# Canal Balance Scenarios v0.1

## Purpose

These automated scenarios protect the first playable economic loop. They do not claim that the global game is balanced; they make sure a future code change cannot silently break the first Canal venue's intended trade-offs.

| Scenario | What must remain true |
| --- | --- |
| Healthy first week | A competent Master, `$24` entry and two modest sessions admit `65-75` guests and make `$400-$650` before loans and construction. |
| Unsupported price increase | Raising admission to `$32` without improving the offer lowers attendance and produces less net result than the healthy `$24` plan. |
| Capacity before demand | Program Sauna Volume creates visible seats and only a small, explained Classic Ritual venue-fit lift. It remains unprofitable by itself; its operating cost is real until demand/programming also improve. |
| Social fit | A fitting Social Energy Gus can fill the Bench Refit's extra seats before a new room is necessary. |
| Recovery truth | A program that advertises Cold Plunge or Outdoor Shower has a bad Venue Fit until that visible asset exists. |
| Debt pressure | A loan repayment is deducted separately from ordinary operating result, rather than hidden in venue costs. |

## How To Use This File

When tuning a price, a demand rule, an upgrade effect or a Master capability, run the scenario tests first. If an intended change alters a scenario, update this document and the test together. Do not change a test merely to make a broken result pass.

## Current Scope

The scenarios cover a single Master, a single active Gus lane and the Canal Workshop. Later additions must add rather than overwrite cases for parallel Masters, recovery queues, staff workload, trend shifts and multi-venue debt.
