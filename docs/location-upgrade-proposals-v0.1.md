# Location Upgrade Proposals v0.1

## Use

This is the detailed owner-review sheet for all location-owned upgrades. It translates the inventory in `location-upgrade-review-v0.1.md` into actual game effects, rough exterior appearance and animation/route work.

`Level 1` is the location-specific facility. `Level 2` and `Level 3` strengthen its primary job. A Level 4 appears only where it creates a genuinely new credible route or use. Values remain provisional until the automated balance sweep.

Canal, Harbour and Industrial District are approved at this level of detail. The remaining packages are proposals for owner review. Building-owned additions are deliberately excluded.

### Approved Forest Lake Effect Notes

- The terrace, platform, spa, fire clearing and shelter improve recovery capacity or retention through a completed post-Gus journey.
- Bridge and shower improve real water-route capability and flow; the Outdoor Gus Sauna adds program capacity and program-specific price acceptance only when delivery is good.
- Stone Circle, View Frame and Ritual Path each add a narrow `Calm`/`Ritual` visible-promise contribution: they improve attraction and credible premium pricing only for guests/programs that value that promise, never all demand.
